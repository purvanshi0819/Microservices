# Microservices with Spring Boot & Spring Cloud

A comprehensive, hands-on journey through building production-grade microservices using Java, Spring Boot, and Spring Cloud — organized as a progressive series of modules from the basics all the way to Kubernetes and Helm.

---

## 📚 Modules

| # | Topic | Key Concepts |
|---|-------|-------------|
| 01 | **Services & Docker** | Building microservices, containerization with Docker, Docker Compose |
| 02 | **Configuration Management** | Externalized config with Spring Cloud Config Server |
| 03 | **MySQL Database** | Integrating MySQL with Spring Data JPA across services |
| 04 | **Service Discovery & Registration** | Eureka Server, client-side load balancing |
| 05 | **API Gateway** | Spring Cloud Gateway, routing and filtering |
| 06 | **Resilience4j** | Circuit breakers, retry, rate limiting, bulkhead patterns |
| 07 | **Observability & Monitoring** | Distributed tracing, metrics, Grafana, Prometheus, Zipkin |
| 08 | **OAuth2 Security** | Securing services with Keycloak and OAuth2/OpenID Connect |
| 09 | **Event-Driven Microservices (RabbitMQ)** | Async messaging with Spring AMQP and RabbitMQ |
| 10 | **Apache Kafka** | Event streaming with Kafka, producers and consumers |
| 11 | **Kubernetes** | Container orchestration, deployments, services, ConfigMaps |
| 12 | **Helm** | Packaging and deploying Kubernetes apps with Helm charts |
| 13 | **Server-Side Discovery & Load Balancing** | Load balancing strategies in a Kubernetes-native setup |

---

## 🛠️ Tech Stack

- **Language:** Java
- **Framework:** Spring Boot, Spring Cloud
- **Databases:** H2, MySQL
- **Messaging:** RabbitMQ, Apache Kafka
- **Security:** OAuth2, Keycloak
- **Containerization:** Docker, Docker Compose
- **Orchestration:** Kubernetes, Helm
- **Observability:** Prometheus, Grafana, Zipkin
- **Resilience:** Resilience4j

---

## 🚀 Getting Started

### Prerequisites

- Java 17+
- Maven
- Docker & Docker Compose
- (For later modules) kubectl and a running Kubernetes cluster (e.g. minikube)
